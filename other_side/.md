# Team Agent System

Multi-agent orchestration system with persistent agents, peer-to-peer communication, and autonomous task selection. Built to integrate with SDX Agent for collaborative AI-powered development.

## 🌟 Key Features

### Persistent Agents
- Agents remain active across multiple tasks
- Context accumulates over time
- Build knowledge and relationships

### Autonomous Task Selection
- Agents evaluate and self-assign tasks
- Score tasks based on specialization and priority
- Make independent decisions

### Peer-to-Peer Communication
- Direct messaging between agents
- Broadcast to entire team
- Escalation to Team Lead

### Planning Mode
- Agents research before executing
- Submit plans for approval
- Iterate based on feedback

### Delegation Mode
- Team Lead coordinates, doesn't execute
- Pure orchestration role
- Clear separation of concerns

### Dependency Management
- Tasks can depend on other tasks
- Automatic dependency resolution
- Parallel execution when possible

### 3. Or Use Programmatically

```python
from team_agent import TeamLeadOrchestrator
import os

# Initialize
api_key = os.getenv("GEMINI_API_KEY")
team_lead = TeamLeadOrchestrator(
    api_key=api_key,
    delegation_mode=True,
    planning_mode=False
)

# Spawn team
team_config = [
    {"role": "Backend Dev", "specialization": ["python", "api"]},
    {"role": "Frontend Dev", "specialization": ["javascript", "react"]},
    {"role": "QA Engineer", "specialization": ["testing"]}
]
agent_ids = team_lead.spawn_team(team_config)

# Create tasks
task1 = team_lead.create_task(
    title="Build API",
    description="Create REST API with authentication",
    required_skills=["python", "api"],
    priority=10
)

task2 = team_lead.create_task(
    title="Build UI",
    description="Create login interface",
    dependencies=[task1],  # Depends on API
    required_skills=["javascript", "react"],
    priority=8
)

# View status
status = team_lead.get_team_status()
print(status)
```

## 🏗️ Architecture

### Core Components

#### 1. Task Queue Manager
```python
class TaskQueueManager:
    - add_task(task)
    - get_available_tasks()
    - assign_task(task_id, agent_id)
    - complete_task(task_id, result)
    - can_start_task(task_id)  # Dependency check
```

**Task States:**
- `READY` - Available for assignment
- `IN_PROGRESS` - Being worked on
- `COMPLETED` - Finished successfully
- `BLOCKED` - Dependencies not met
- `FAILED` - Execution failed

#### 2. Message Bus
```python
class MessageBus:
    - send(message)
    - receive(agent_id)
    - get_unread_count(agent_id)
```

**Message Types:**
- `INFO` - Status updates, findings
- `REQUEST` - Ask for help
- `RESPONSE` - Reply to requests
- `ALERT` - Urgent notifications
- `PLAN_SUBMISSION` - Submit plan for review
- `PLAN_FEEDBACK` - Plan approval/rejection

#### 3. Agent Session Manager
```python
class AgentSessionManager:
    - spawn_agent(role, specialization)
    - get_agent(agent_id)
    - update_agent_status(agent_id, status)
    - shutdown_agent(agent_id)
```

**Agent States:**
- `IDLE` - Waiting for tasks
- `WORKING` - Executing task
- `PLANNING` - Creating execution plan
- `WAITING_APPROVAL` - Plan submitted
- `SHUTDOWN` - Terminated

#### 4. Planning Mode Manager
```python
class PlanningModeManager:
    - create_plan(plan)
    - approve_plan(plan_id)
    - reject_plan(plan_id, feedback)
```

#### 5. Permission Manager
```python
class PermissionManager:
    - spawn_agent(agent_id)  # Inherits Team Lead permissions
    - get_permissions(agent_id)
    - has_permission(agent_id, permission)
```

#### 6. Autonomy Engine
```python
class AutonomyEngine:
    - evaluate_task_fit(agent, task) -> score
    - select_best_task(agent, available_tasks) -> task
    - should_request_help(agent, task) -> bool
```

### Workflow Example

```
1. Team Lead creates tasks with dependencies
   ├─ Task A: Build API (no deps)
   ├─ Task B: Build UI (depends on A)
   └─ Task C: Write Tests (depends on A, B)

2. Team Lead spawns agents
   ├─ Backend Developer
   ├─ Frontend Developer
   └─ QA Engineer

3. Agents autonomously select tasks
   Backend Dev sees Task A matches their skills
   → Self-assigns Task A
   → Executes
   → Completes
   → Broadcasts: "API ready at /api/auth"

4. Frontend Dev receives message
   → Sees Task B now available (deps met)
   → Self-assigns Task B
   → Sends message to Backend: "Need API docs"
   → Backend responds with documentation
   → Completes UI

5. QA Engineer
   → Sees Task C now available
   → Self-assigns
   → Reads API and UI code
   → Writes integration tests
   → Completes
```

## 🎛️ Configuration Options

### Delegation Mode
```python

delegation_mode=True

# OFF: Team Lead can execute tasks directly
delegation_mode=False
```

### Planning Mode
```python
# ON: Agents must submit plans for approval
planning_mode=True

# OFF: Agents execute immediately
planning_mode=False
```

### Auto-Reject First Plan
```python
# Force agents to iterate on plans
always_reject_first_plan=True
```

### Permission Configuration
```python
base_permissions = {
    "file_read": True,
    "file_write": True,
    "file_delete": False,
    "code_execution": True,
    "network_access": True,
    "dangerous_skip": False
}
```

## 🔐 Security Considerations

### Permission Inheritance
All agents inherit permissions from Team Lead:
- If Team Lead has `file_write: True` → All agents can write files
- If Team Lead has `dangerous_skip: True` → All agents can skip confirmations
- No agent can have more permissions than Team Lead

### Resource Management
Always shutdown teams when done:
```python
team_lead.shutdown_team()
```

This prevents:
- Resource leaks
- Orphaned processes
- Context pollution

## 🐛 Troubleshooting

### Agents Not Selecting Tasks
**Problem:** Idle agents don't self-assign tasks

**Solution:**
```python
# Check task availability
available = team_lead.task_queue.get_available_tasks()

# Check dependencies
for task in available:
    can_start = team_lead.task_queue.can_start_task(task.task_id)
    print(f"{task.title}: {can_start}")

# Check agent specialization match
from team_agent import AutonomyEngine
score = AutonomyEngine.evaluate_task_fit(agent, task)
print(f"Fit score: {score}")
```

### Plans Stuck in Pending
**Problem:** Plans never get approved

**Solution:**
```python
# Check pending plans
pending = team_lead.planning_manager.get_pending_plans()

# Manually review
for plan in pending:
    team_lead.review_plan(plan.plan_id)
```

### Messages Not Received
**Problem:** Agents not seeing messages

**Solution:**
```python
# Check message bus registration
team_lead.message_bus.register_agent(agent_id)

# Check unread count
count = team_lead.message_bus.get_unread_count(agent_id)

# Receive messages
messages = team_lead.message_bus.receive(agent_id)
```
