# Agent Teams - Architecture & Implementation Guide

## Overview

Agent Teams is a multi-agent orchestration system that enables parallel, persistent AI agents to collaborate on complex tasks. Unlike traditional sub-agent patterns, Agent Teams implements a fully autonomous, peer-to-peer collaborative framework.

---

## Core Architecture

### 1. Orchestration Model

```
┌─────────────────────────────────────────┐
│           Team Lead (Orchestrator)       │
│  - Task Planning & Distribution          │
│  - Resource Management                   │
│  - Team Coordination                     │
│  - Quality Control                       │
└──────────────┬──────────────────────────┘
               │
       ┌───────┴───────┐
       │ Task Queue    │
       │ with          │
       │ Dependencies  │
       └───────┬───────┘
               │
    ┌──────────┼──────────┐
    │          │          │
┌───▼───┐  ┌──▼────┐  ┌──▼────┐
│Agent 1│  │Agent 2│  │Agent 3│
│       │◄─┤       │◄─┤       │
│       ├─►│       ├─►│       │
└───────┘  └───────┘  └───────┘
   Peer-to-Peer Communication
```

### 2. Key Architectural Differences

#### Traditional Sub-Agents (Non-Persistent)
```
Manager → Sub-Agent → Execute → Terminate → Return Result
          (Spawned)              (Dies)
          
- Single session lifecycle
- One task = One agent
- Sequential execution
- No inter-agent communication
- Results flow only upward
```

#### Agent Teams (Persistent)
```
Team Lead → Agent 1 (spawned) → Task 1 → Task 2 → Task 3 → ...
                     ↓                                        ↑
                     ├─────→ Agent 2 ←──────────────────────┤
                     ↓                                        ↑
                     └─────→ Agent 3 ←──────────────────────┘
                     
- Multi-session lifecycle
- One agent = Multiple tasks
- Parallel execution
- Full peer-to-peer communication
- Agents persist until explicitly terminated
```

#### Task Structure

#### Task States
- **Ready**: Task available for assignment, all dependencies met
- **In Progress**: Agent actively working on task
- **Completed**: Task finished, result available
- **Blocked**: Dependencies not yet resolved

#### Dependency Resolution Logic

```python
def can_start_task(task):
    """Check if task dependencies are satisfied"""
    for dependency_id in task.dependencies:
        dependency = get_task(dependency_id)
        if dependency.status != "completed":
            return False
    return True

def get_available_tasks(agent):
    """Get tasks that agent can work on"""
    tasks = []

        if task.status == "ready" and can_start_task(task):
```

#### Communication Patterns

**1. Direct Messaging (Agent to Agent)**
```
Agent A → Message → Agent B
         (Specific communication)
```

**2. Group Messaging**
```
Agent A → Message → [Agent B, Agent C, Agent D]
         (Multiple recipients)
```

**3. Broadcast**
```
Agent A → Message → All Agents + Team Lead
         (Team-wide announcements)
```

**4. Team Lead Escalation**
```
Any Agent → Critical Issue → Team Lead
           (Requires decision/approval)
```

#### Implementation Pattern
```python
class MessageBus:
    def __init__(self):
        self.messages = {}
        self.subscriptions = {}
    
    def send(self, from_agent, to_agents, message):
        """Send message to specific agents"""
        for agent_id in to_agents:
            if agent_id not in self.messages:
                self.messages[agent_id] = []
            self.messages[agent_id].append({
                'from': from_agent,
                'message': message,
                'timestamp': now()
            })
    
    def broadcast(self, from_agent, message):
        """Broadcast to all agents"""
        for agent_id in self.subscriptions:
            self.send(from_agent, [agent_id], message)
    
    def receive(self, agent_id):
        """Get messages for specific agent"""
        return self.messages.get(agent_id, [])
```


### 4. Autonomy & Self-Assignment

#### Agent Decision Making
```python
class AutonomousAgent:
    def select_next_task(self, available_tasks):
        """Agent chooses most suitable task"""
        scores = []
        for task in available_tasks:
            score = self.evaluate_task_fit(task)
            scores.append((task, score))
        
        # Sort by best fit
        scores.sort(key=lambda x: x[1], reverse=True)
        return scores[0][0] if scores else None
    
    def evaluate_task_fit(self, task):
        """Score task based on agent specialization"""
        score = 0
        
        # Match with role specialization
        if self.role in task.required_skills:
            score += 50
        
        # Consider current context
        if task.relates_to_previous_work(self.tasks_completed):
            score += 30
        
        # Priority weight
        score += task.priority * 10
        
        return score
```

#### Self-Assignment Flow
```
1. Agent completes task
2. Agent queries task queue for available tasks
3. Agent evaluates each task against capabilities
4. Agent selects best-fit task
5. Agent assigns task to self
6. Team Lead is notified
7. Agent begins work
```

### 5. Planning Mode

Planning Mode ensures agents think before acting, requiring approval before execution.

#### Planning Mode Architecture
```
┌──────────────────────────────────────────┐
│  Agent receives task                      │
└────────────────┬─────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────┐
│  Research & Analysis (Read-only)          │
│  - Explore codebase                       │
│  - Read documentation                     │
│  - Analyze requirements                   │
│  - NO file modifications allowed          │
└────────────────┬─────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────┐
│  Create Detailed Plan                     │
│  - Step-by-step approach                  │
│  - File changes needed                    │
│  - Potential risks                        │
│  - Success criteria                       │
└────────────────┬─────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────┐
│  Submit to Team Lead for Review           │
└────────────────┬─────────────────────────┘
                 │
         ┌───────┴───────┐
         │               │
    Rejected         Approved
         │               │
         ▼               ▼
   ┌─────────┐     ┌──────────┐
   │ Revise  │     │ Execute  │
   │ Plan    │     │ Plan     │
   └────┬────┘     └──────────┘
        │
        └─→ Resubmit
```

#### Planning Workflow Implementation
```python
class PlanningMode:
    def __init__(self):
        self.plans = {}
    
    def create_plan(self, agent_id, task):
        """Agent creates execution plan"""
        plan = {
            'agent_id': agent_id,
            'task_id': task.id,
            'research_phase': self.conduct_research(task),
            'proposed_steps': self.outline_steps(task),
            'files_to_modify': self.identify_files(task),
            'risks': self.assess_risks(task),
            'status': 'pending_approval',
            'version': 1
        }
        self.plans[task.id] = plan
        return plan
    
    def review_plan(self, team_lead, plan_id):
        """Team lead reviews and approves/rejects"""
        plan = self.plans[plan_id]
        review = team_lead.evaluate_plan(plan)
        
        if review.approved:
            plan['status'] = 'approved'
            return {'approved': True}
        else:
            plan['status'] = 'needs_revision'
            plan['feedback'] = review.feedback
            plan['version'] += 1
            return {
                'approved': False,
                'feedback': review.feedback
            }
```

```python
def evaluate_plan(plan):
```

### 6. Delegation Mode

Delegation Mode prevents the Team Lead from executing tasks directly, ensuring pure coordination.

#### Delegation Logic
```python
class TeamLead:
    def __init__(self, delegation_mode=False):
        self.delegation_mode = delegation_mode
        self.can_execute_tasks = not delegation_mode
    
    def handle_task(self, task):
        """Team lead processes task request"""
        if self.delegation_mode:
            # Must delegate, cannot execute
            return self.delegate_task(task)
        else:
            # Can choose to delegate or execute
            if self.should_delegate(task):
                return self.delegate_task(task)
            else:
                return self.execute_task(task)
    
    def delegate_task(self, task):
        """Assign task to team member"""
        suitable_agents = self.find_suitable_agents(task)
        
        if not suitable_agents:
            return {
                'status': 'error',
                'message': 'No suitable agent available'
            }
        
        best_agent = self.select_best_agent(suitable_agents, task)
        return self.assign_task_to_agent(best_agent, task)
```

#### Team Lead Responsibilities (Delegation Mode)
- ✅ Create task queue
- ✅ Define task dependencies
- ✅ Assign tasks to agents
- ✅ Review plans and progress
- ✅ Coordinate between agents
- ✅ Handle escalations
- ❌ Execute tasks directly
- ❌ Modify files
- ❌ Write code

### 7. Permission Inheritance

All team members inherit permissions from the Team Lead.

#### Permission Model
```python
class PermissionManager:
    def __init__(self, team_lead_permissions):
        self.base_permissions = team_lead_permissions
        self.agent_permissions = {}
    
    def spawn_agent(self, agent_id):
        """New agent inherits Team Lead permissions"""
        self.agent_permissions[agent_id] = self.base_permissions.copy()
        return self.agent_permissions[agent_id]
    
    def get_permissions(self, agent_id):
        """Get agent's inherited permissions"""
        return self.agent_permissions.get(agent_id, [])
```

## Resource Management

### Agent Lifecycle Management
```python
class TeamManager:
    def __init__(self):
        self.active_agents = {}
        self.agent_resources = {}
    
    def shutdown_agent(self, agent_id):
        """Properly terminate agent and release resources"""
        if agent_id in self.active_agents:
            agent = self.active_agents[agent_id]
            
            # Save final state
            self.save_agent_state(agent)
            
            # Release resources
            self.release_resources(agent_id)
            
            # Remove from active pool
            del self.active_agents[agent_id]
    
    def shutdown_team(self):
        """Shutdown all agents"""
        for agent_id in list(self.active_agents.keys()):
            self.shutdown_agent(agent_id)
```

**Important:** Always explicitly shutdown teams to prevent resource leaks and ensure clean state for future tasks.

## Conclusion

Agent Teams represents a paradigm shift from ephemeral sub-agents to persistent, collaborative AI teams. The key innovations are:

1. **Persistence** - Agents that learn and grow
2. **Autonomy** - Self-directed task selection
3. **Collaboration** - Direct peer communication
4. **Planning** - Think before acting
5. **Delegation** - Pure coordination from Team Lead

This architecture enables tackling complex, multi-faceted problems that single-agent or sub-agent systems struggle with, while maintaining clarity through structured task management and explicit communication channels.
